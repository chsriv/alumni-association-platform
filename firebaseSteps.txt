🔥 FIREBASE SETUP INSTRUCTIONS FOR ALUMNI NETWORK ANALYSIS PLATFORM
=========================================================================

STEP 1: CREATE FIREBASE PROJECT
--------------------------------
1. Go to https://console.firebase.google.com/
2. Click "Add Project" or "Create a Project"
3. Enter project name: "alumni-network-platform" (or your choice)
4. Accept terms and click "Continue"
5. Disable Google Analytics (optional for this project) or link Analytics account
6. Click "Create Project"
7. Wait for project creation (~30 seconds)
8. Click "Continue" when ready


STEP 2: SET UP FIRESTORE DATABASE
----------------------------------
1. In Firebase Console, click "Firestore Database" from left sidebar
2. Click "Create Database" button
3. Choose "Start in TEST MODE" (for development)
   - Note: This allows read/write access for 30 days
   - Later, we'll add security rules for production
4. Select Cloud Firestore location (choose closest to your region):
   - For India: asia-south1 (Mumbai)
   - For US: us-central1
5. Click "Enable"
6. Wait for database provisioning


STEP 3: SET UP FIREBASE AUTHENTICATION
---------------------------------------
1. Click "Authentication" from left sidebar
2. Click "Get Started" button
3. Click "Sign-in method" tab
4. Enable "Email/Password" provider:
   - Click on "Email/Password" row
   - Toggle "Enable" switch to ON
   - Click "Save"
5. (Optional) Enable "Google" sign-in for easier login


STEP 4: GET FIREBASE CONFIGURATION
-----------------------------------
1. Click the ⚙️ (gear icon) next to "Project Overview" in left sidebar
2. Click "Project settings"
3. Scroll down to "Your apps" section
4. Click the </> (Web) icon to add a web app
5. Enter app nickname: "Alumni Portal Web App"
6. Check "Also set up Firebase Hosting" (optional)
7. Click "Register app"
8. COPY the firebaseConfig object - it looks like this:

   const firebaseConfig = {
     apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX",
     authDomain: "alumni-network-platform.firebaseapp.com",
     projectId: "alumni-network-platform",
     storageBucket: "alumni-network-platform.appspot.com",
     messagingSenderId: "123456789012",
     appId: "1:123456789012:web:abcdef1234567890"
   };

9. SAVE this configuration - you'll need it in the next step!
10. Click "Continue to console"


STEP 5: ADD FIREBASE SDK TO YOUR PROJECT
-----------------------------------------
1. Open "alumni-frontend.html" in your code editor
2. Find the closing </head> tag (around line 20)
3. Add these script tags BEFORE </head>:

   <!-- Firebase App (the core Firebase SDK) -->
   <script src="https://www.gstatic.com/firebasejs/10.7.1/firebase-app-compat.js"></script>
   <!-- Firebase Firestore -->
   <script src="https://www.gstatic.com/firebasejs/10.7.1/firebase-firestore-compat.js"></script>
   <!-- Firebase Authentication -->
   <script src="https://www.gstatic.com/firebasejs/10.7.1/firebase-auth-compat.js"></script>

4. Save the file


STEP 6: CREATE FIREBASE CONFIGURATION FILE
-------------------------------------------
1. Create a new file named "firebase-config.js" in your project folder
2. Paste the following code, replacing with YOUR firebaseConfig from Step 4:

   // Firebase Configuration
   const firebaseConfig = {
     apiKey: "YOUR_API_KEY_HERE",
     authDomain: "YOUR_PROJECT_ID.firebaseapp.com",
     projectId: "YOUR_PROJECT_ID",
     storageBucket: "YOUR_PROJECT_ID.appspot.com",
     messagingSenderId: "YOUR_SENDER_ID",
     appId: "YOUR_APP_ID"
   };

   // Initialize Firebase
   firebase.initializeApp(firebaseConfig);

   // Initialize Services
   const db = firebase.firestore();
   const auth = firebase.auth();

   console.log("✅ Firebase initialized successfully!");

3. Save the file


STEP 7: LINK FIREBASE CONFIG TO HTML
-------------------------------------
1. Open "alumni-frontend.html"
2. Find the line that loads script.js (near the end, before </body>)
3. Add this line BEFORE <script src="script.js"></script>:

   <script src="firebase-config.js"></script>

4. Save the file


STEP 8: TEST FIREBASE CONNECTION
---------------------------------
1. Open "alumni-frontend.html" in your browser
2. Open Developer Console (F12 or Right-click → Inspect → Console)
3. Look for: "✅ Firebase initialized successfully!"
4. If you see this message, Firebase is connected! ✅
5. If you see errors, double-check your firebaseConfig values


STEP 9: SEED INITIAL DATA TO FIRESTORE
---------------------------------------
1. In Firebase Console, go to "Firestore Database"
2. Click "Start collection"
3. Collection ID: "alumni"
4. Click "Next"
5. Add first document:
   - Document ID: (auto-generate)
   - Add fields:
     * name (string): "Dr. Rajesh Kumar"
     * stream (string): "Computer Science"
     * year (number): 2015
     * company (string): "Google"
     * role (string): "Senior Engineer"
     * connections (array): [] (empty for now)
6. Click "Save"
7. Repeat for 2-3 more alumni records


STEP 10: UPDATE SECURITY RULES (IMPORTANT!)
--------------------------------------------
1. In Firestore Database, click "Rules" tab
2. Replace default rules with:

   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       // Allow read access to all users
       match /{document=**} {
         allow read: if true;
         allow write: if request.auth != null; // Only authenticated users can write
       }
     }
   }

3. Click "Publish"
4. This allows anyone to read data, but only logged-in users can modify


STEP 11: VERIFY EVERYTHING WORKS
---------------------------------
✅ Firebase Console shows your project
✅ Firestore Database has "alumni" collection with data
✅ Authentication is enabled
✅ Browser console shows "Firebase initialized successfully"
✅ No red errors in browser console


STEP 12: DELETE THIS FILE
--------------------------
Once all steps above are completed successfully, you can DELETE this file:
- Right-click on firebaseSteps.txt → Delete
- Or run in terminal: del firebaseSteps.txt

The Firebase setup is now complete! 🎉

TROUBLESHOOTING:
----------------
❌ Error: "Firebase is not defined"
   → Check that Firebase scripts are loaded BEFORE firebase-config.js

❌ Error: "Permission denied"
   → Check Firestore Security Rules (Step 10)

❌ Error: "Invalid API key"
   → Double-check firebaseConfig values match your Firebase Console

❌ Browser shows blank page
   → Open Developer Console (F12) to see specific error messages
